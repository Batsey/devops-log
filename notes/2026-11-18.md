COMMANDS

sudo systemctl stop UNIT       stop (more than one unit allowed)

sudo ss -tlnp | grep :22       who is listening on port 22
ssh localhost                  connect to my own machine

RULES
- Package name and service name can differ:
  openssh-server (package) -> ssh (service); sshd on Red Hat
- enabled = starts at boot; active = running now; independent
  (Windows: Automatic/Manual vs Running)
- systemd "disabled" = Windows Manual; "masked" = Windows Disabled
- "since" time unchanged = it never restarted
- Status only reads, so no sudo; start/stop change things, so sudo

LEARNED
- Ubuntu 22.10+: ssh.socket holds port 22; systemd owns it and
  starts ssh.service on the first connection
- Stopping ssh.service alone doesn't close SSH: the socket wakes
  it again (systemd warns about this)
- To refuse SSH, stop ssh.socket and ssh
- After waking, ssh.service keeps running after exit
- ○ = not running, ● = running; dead = stopped, failed = crashed
- remove/purge never touch /home; purge deletes /etc config
- apt-get in scripts: stable output; apt can change between versions
- Options are case-sensitive: -y is not -Y
- ps aux | grep X: the grep line matches itself (COMMAND column)
