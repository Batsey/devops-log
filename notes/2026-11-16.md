LEARNED
- Unquoted *.log: bash swaps in EVERY match in this folder
  (0 = works by luck, 1 = wrong results, 2+ = error)
- grep reads contents (needs -r for folders); find reads names
- Command line = command, options, argument
- -ld/root fails: options and argument need a space between
- uid 0 = root; first normal user = 1000
- sudo changes the USER a command runs as, not the CPU mode
- ls /root = look inside (denied); ls -ld /root = read the
  label from / (allowed)
- /root is 700; new homes are 750 (Ubuntu 21.04+)
- -G without -a REPLACES extra groups (like > vs >>)
- Main group can't be removed by -G
- sudo asks for the runner's password; remembers ~15 min
- Many commands print nothing on success
- My ls and sudo show newer error wording; commands are the same

COMMANDS
sudo apt update              refresh the LIST of available versions
sudo apt upgrade             install newer versions of what I have
apt search WORD              search names AND descriptions (noisy)
apt show NAME                one package's details
apt show NAME | grep Version pick one line out of the output
sudo apt install NAME        install a package
which NAME                   full path to a program, or nothing
tree FOLDER                  draw a folder as a tree

LEARNED
- update = the list, upgrade = the programs; update first
- Reading the list needs no sudo; update/install/upgrade write
  to root's folders, so they need sudo
- Options change how a command behaves; grep picks lines out
  of output (apt show tree --version printed apt's version)
- wc -l counts lines, not results (apt search uses ~3 per result)
- apt's WARNING goes to stream 2, so it skips the pipe
- On a real server, upgrade is a deliberate change
