COMMANDS
ls -l                  show permissions
./script.sh            run a script in this folder
chmod u+x file         add execute for the owner
chmod 755 file         rwxr-xr-x
chmod 644 file         rw-r--r--
find . -type f -name "*.sh" | xargs chmod 755

NUMBERS
r = 4    w = 2    x = 1    - = 0
7 = rwx  6 = rw-  5 = r-x  4 = r--
Order: user, group, others

LEARNED
- First character: - is a file, d is a folder
- w = change it, x = run it; they're separate
- "Permission denied" when running = no x
- An empty script runs and prints nothing
- 644: files nobody runs (notes, logs, config)
- 755: scripts and programs
- 600: only me, read and write (SSH private key)
- Bash swaps unquoted *.log before find runs
- . means the folder I'm in, not "all"
- Always give find a starting folder; macOS needs it
