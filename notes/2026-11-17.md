COMMANDS
grep -rl WORD .                     files whose CONTENTS have WORD
find . -name "*.conf" | xargs grep -l WORD   name AND contents
sudo apt remove NAME                remove program, keep /etc config
sudo apt purge NAME                 remove program AND /etc config
sudo apt-get update                 script version of apt update
sudo apt-get install -y NAME        script version; -y = yes in advance
sleep 300 &                         run in the background
ps                                  processes in this terminal
ps aux                              every process on the system
ps aux | grep NAME                  find one process
kill PID                            ask a process to stop
kill %1                             same, by job number

RULES
grep and find
- Only contents -> grep -rl WORD .
- Only names -> find . -name "PATTERN"
- Both -> find . -name "PATTERN" | xargs grep -l WORD
- -r only when grep gets a folder; after xargs it gets files
- grep -r with no folder searches . (can "work" by luck)
Pipe vs xargs
- Search the text itself -> pipe straight into grep
- Search inside the files named in the text -> xargs
apt
- At the keyboard: apt. In scripts: apt-get with -y
- update = the list, upgrade = the programs; update first
- Reading needs no sudo; update/install/remove write -> sudo
- remove keeps /etc config; purge deletes it (careful with SSH)
- Neither touches my home folder
- Without -y, a script hangs, or aborts and carries on
  without the package
Processes
- Program = file on disk; process = a running copy, with a PID
- Every run gets a new PID
- CAPITALS in instructions are placeholders: replace them
- ps aux | grep X also shows the grep itself; ignore that line
- ps aux takes no dash (old style); don't copy that elsewhere

LEARNED
- bash is the shell; apt-get is a separate program it starts
- command-not-found suggests the package for a missing command
- [1] 1544 = job number, then PID
- ps columns: PID, TTY (pts/0 = my window), TIME = CPU time, CMD
- ps aux adds USER, %CPU, %MEM, STAT (S = waiting, + = foreground)
